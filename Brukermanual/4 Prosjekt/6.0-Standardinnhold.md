# Standardinnhold


Prosjekter kan opprettes med standardinnhold som er definert på porteføljenivå. Hvilket standardinnhold som følger med et nytt prosjekt, avhenger av prosjektmalen som brukes.

Standardinnhold kan blant annet omfatte **interessenter, prosjektoppgaver, dokumenter og fasesjekkpunkter**.

Prosjektportalen bruker standardinnhold basert på **Prosjektveiviseren v6 fra Digdir**. Fasesjekkpunkter og prosjektoppgaver er organisert i egne innholdssett, slik at ulike prosjektmaler kan bruke forskjellig standardinnhold.

Når prosjektet opprettes, legges standardinnholdet som er valgt for prosjektmalen, til i prosjektet. Prosjektgruppen kan deretter supplere med eget innhold etter behov.
